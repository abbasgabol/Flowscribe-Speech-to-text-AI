Local Dictation 0.3.0 beta for Windows 10/11 x64.

Download **LocalDictation-Setup.exe**, open it, accept the MIT license, and choose
your installation location, model components, and desktop shortcut options.
Python, dependencies, and models are bundled; installation and dictation work offline.

- Hold Win + Alt to speak; release to insert text.
- Local punctuation, clock-phrase formatting, and explicitly saved corrections.
- Lightweight model included; Complete installation adds Accuracy.
- Uninstall through Windows Installed Apps; saved preferences are preserved.

The installer is unsigned; Windows may show an unknown-publisher warning.
Recognition is imperfect. Review important text. This beta was tested on the
development Windows PC, including installation, transcription, and uninstallation.
